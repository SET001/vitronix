# Contributing

## Naming

- Use singular nouns for names representing one entity. For example, use
  `PanelTemplateRegistry`, not `PanelsTemplateRegistry`. Use plural names only
  for collections of entities.
- Name UI components after the entity they represent, such as `Container` or
  `Panel`, rather than adding a `Component` suffix.
- Name component parameter types after the entity with a `Params` suffix, such
  as `ContainerParams` or `PanelParams`.
